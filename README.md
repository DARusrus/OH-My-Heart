<br/>

**CardioRisk AI** is a full-stack machine learning project that classifies cardiovascular disease from routine clinical vitals. It goes far beyond a simple accuracy number — the model is **calibrated**, **explained per-patient using SHAP**, **hyperparameter-tuned with Optuna**, **validated with 5-fold stratified CV**, and **deployed as a live interactive app**. Every decision in the pipeline — from outlier thresholds to classification thresholds — is grounded in published clinical guidelines (JNC-8, WHO, ACC/AHA, Framingham).

<h2>⚡ &nbsp;Installation &amp; Usage</h2>
</div>

**Option 1 — Try the live demo (zero setup)**

Click the **🚀 LIVE DEMO** button at the top of this README.

---

**Option 2 — Run on Kaggle (recommended)**

1. Open the [Kaggle Notebook](#) and click **Copy & Edit**
2. Add the dataset → `Notebook Settings → Add Data → search` **cardiovascular-disease-dataset** by *sulianova*
3. Enable GPU → `Notebook Settings → Accelerator → GPU T4 x2`
4. Run all cells top-to-bottom (Snippet 1 → 5)
5. The Gradio `share=True` URL appears at the end of Snippet 5

---

**Option 3 — Run locally**

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/cardiorisk-ai.git
cd cardiorisk-ai

# 2. Install all dependencies
pip install xgboost lightgbm scikit-learn shap gradio==5.29.0 \
            optuna pandas numpy matplotlib seaborn joblib

# 3. Download the dataset from Kaggle
#    Place cardio_train.csv in a /data/ directory
#    kaggle datasets download sulianova/cardiovascular-disease-dataset

# 4. Launch the notebook
jupyter notebook cardiorisk_classifier.ipynb
```

> **Note:** XGBoost GPU acceleration requires a CUDA-compatible GPU.
> Set `device="cpu"` in Snippet 3 if running on CPU only.
